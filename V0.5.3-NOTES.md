# ReelMind V0.5.3 — Analyse audiovisuelle + catégories intelligentes

## Objectifs et corrections

- **La légende n'est plus un support suffisant pour résumer** : le résumé automatique est bloqué si ni transcription audio ni analyse visuelle ne sont disponibles. Les métadonnées Instagram continuent à être extraites et affichées sans IA.
- La transcription n'est plus conditionnée à l'absence de légende ou d'auteur. Si le texte transcrit existe déjà, il est réutilisé.
- yt-dlp sélectionne maintenant `bestaudio[ext=m4a]/bestaudio[ext=mp3]/bestaudio`, puis un fichier vidéo combiné si la piste audio distincte est absente. Groq accepte notamment les extensions m4a, mp3, ogg, webm et mp4 (respecter ses limites de taille).
- Quand le traitement des images est activé, un fichier vidéo temporaire peut être téléchargé pour prélever jusqu'à trois images clés locales avec `MediaMetadataRetriever`, puis analysées par Gemini Vision. Les URLs d'images publiques des posts/carrousels sont prises en charge en mode JSON, au mieux (max. 3 photos / 4 Mo chacune). **Ce n'est pas un OCR garanti ni une analyse de toutes les frames.**
- Après transcription (et éventuelle analyse de quelques images), un seul appel de synthèse génère : titre IA, résumé, points clés, étapes / lieux / références *lorsque présents*, catégorie et mots-clés.
- **Aucun retry automatique** de transcription, d'analyse visuelle ou de résumé si un fournisseur IA échoue. Les relances sont manuelles.
- Les titres manuels restent prioritaires, et les anciens titres ne sont pas recalculés.

## Catégories (fonctions prévues initialement en V0.5.4)

- 0–10 mots-clés personnalisés par catégorie, persistés dans `categories_all` (SharedPreferences JSON compatible avec les anciens formats).
- Correspondance locale insensible aux accents, sur les mots ou expressions, sans appel API supplémentaire.
- Les fiches déjà classées ne sont jamais déplacées automatiquement par les mots-clés.
- Action manuelle pour classer les fiches « À classer » par mots-clés, sans IA.
- Réorganisation des catégories par flèches haut/bas dans le gestionnaire, avec enregistrement de l'ordre.
- Carte « Plus » de l'accueil pour accéder à toutes les catégories, + engrenage pour les gérer.
- Couleur du bouton flottant explicitement bleue.

## Compatibilité

- package `fr.reelmind.app` inchangé.
- `versionCode=10`, `versionName=0.5.3`, ABI ARM64.
- DB Room reste **version 6**, aucune migration ajoutée.
- Compilation attendue via GitHub Actions avec les mêmes secrets de signature.

## Limitations et tests Android indispensables

1. Compiler dans GitHub Actions puis installer sur l'APK existant avec la même clé. Vérifier les données et catégories.
2. Nouveau Reel avec paroles : vérifier auteur/légende/miniature, télécharger piste audio, obtenir `mediaText`, puis résumé. Tester un Reel qui propose seulement un flux MP4 combiné.
3. Reel muet avec texte à l'écran : vérifier les images clés, la description visuelle et la synthèse.
4. Post photo et carrousel public : vérifier récupération des URL d'images, extraction et analyse. Certaines URL CDN ou pages Instagram peuvent être bloquées.
5. Reel avec seulement légende : vérifier statut bloqué explicite et **absence de synthèse IA**.
6. Couper les clés Groq/Gemini, vérifier l'erreur par étape et l'absence de nouvelle tentative automatique.
7. Créer 10 catégories, déplacer leur ordre, tester les mots-clés et le bouton « Plus ».
8. Vérifier que la correction manuelle de titre est conservée après une relance du traitement.

**Non compris dans cette version** : lecture vidéo intégrée, index inter-fiches de lieux, reconnaissance exhaustive des éléments visuels, glisser-déposer natif des catégories (les flèches haut/bas sont fonctionnelles), validation de build local Android.
