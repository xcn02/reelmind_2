# ReelMind V0.5.3.1 — Visuel conditionnel et carrousels

- ARM64, versionCode 11, versionName 0.5.3.1.
- Vidéos : transcription prioritaire. Nouveau réglage `ex_video_visual` : `auto` (défaut), `off`, `always`.
- `auto` : heuristique locale sur transcription (moins de 65 mots ou références à l'écran) ; seulement alors télécharger la vidéo et produire trois images clés pour Gemini Vision. Cette heuristique peut rater les cas ambigus ; choisir « Toujours » dans les paramètres si nécessaire.
- Légende seule : le résumé reste bloqué si ni transcription ni observation visuelle n'est disponible.
- Carrousels publics : les URL de toutes les diapositives sont parcourues dans leur ordre, jusqu'à 20 médias. Téléchargement temporaire, images analysées dans une unique requête Gemini Vision si accessibles. Le nombre effectif peut être inférieur si Instagram refuse certains médias. Les vidéos intégrées à des carrousels mixtes ne sont pas encore transcrites individuellement.
- Les catégories et mots-clés de V0.5.3 sont conservés.
- Pas de retry d'IA ; une analyse visuelle occasionne une requête Gemini Vision distincte de la requête de résumé. L'heuristique de sélection ne consomme aucun appel API.
- Pas de changement de schéma Room ni de clé de signature.

Contrôles réalisés : compilation Kotlin autonome de VisualDecision et trois assertions. Compilation Android complète non réalisée ; construire via GitHub Actions et vérifier sur téléphone.
