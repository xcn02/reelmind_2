# ReelMind 0.5.4 — Interface, recherche et catégories

Source basée sur V0.5.3.3 (versionCode 14).

## Changements
- Fiche : CTA de discussion contextuelle sous le résumé, au lieu d'un bouton éloigné en bas.
- Recherche : barre de recherche dédiée, compteur de résultats, filtre de catégorie, entrée « Recherche IA » avec étoiles visible dans l'onglet Recherche.
- Recherche IA globale : écran de discussion en plein écran avec bulles, suggestions, historique de cette session transmis dans le prompt (limité à 3 000 caractères). Aucune sauvegarde du chat ; annulation des requêtes en cours et effacement des réponses à la sortie.
- Catégories : « À classer » injectée dans la liste ordonnée même sur les anciennes installations ; peut être déplacée à l'aide de la poignée comme les autres catégories ; ne peut ni être renommée ni supprimée.
- Cartes de catégories réduites à 86 dp ; organisation en deux colonnes conservée.
- Aucune migration Room, pas de changement dans l'extraction/transcription/analyse.

## Limitations / vérifications nécessaires
- La recherche IA globale envoie seulement jusqu'à 25 fiches analysées, sans index vectoriel. Ce n'est pas une recherche exhaustive dans une grande bibliothèque.
- Glisser-déposer : les déplacements sont animés via animateItem, mais la ligne ne suit pas continuellement le doigt.
- Cette archive est du code source ; compilation Android et tests fonctionnels sur téléphone restent à effectuer.
- Utiliser la même signature APK pour préserver les données des installations précédentes.
