# ReelMind V0.5.3.2 — Correctifs diagnostic et catégories

- Source Android ARM64, versionCode 12 (installation en mise à jour de la V0.5.3.1 avec **la même signature**).
- Modèle Gemini : la valeur invalide `gemini-3.8-flash-lite` est corrigée en `gemini-3.8-flash` à l’appel ; le modèle par défaut reste `gemini-3.5-flash-lite`. Aucun appel API de vérification ajouté.
- L'analyse visuelle réutilise la même correction ; seules les images effectivement obtenues sont envoyées.
- La commande manuelle « Réanalyser » force désormais l’analyse même si l'option d’analyse automatique est désactivée. Une transcription déjà enregistrée sert au résumé.
- Lorsque la transcription Groq est activée mais que la clé manque, un message explicite remplace l’échec silencieux.
- Sur les Reels avec transcription suffisante, pas de nouvel appel Vision automatique.
- Accueil : cartes de catégories plus compactes en deux colonnes, avec icône, nom, nombre de fiches ; carte « Plus ».
- Gestionnaire : poignée ≡ à maintenir puis glisser pour déplacer une catégorie, sans flèches. Préservation du JSON SharedPreferences existant, des mots-clés et de la base Room.

## Limites / tests
- Pas de compilation Android ni de test d'appels Gemini/Groq sur téléphone dans cet environnement.
- yt-dlp Instagram peut échouer selon l’accès au média ; l’avertissement `ffmpeg-location` nécessite un test sur l’appareil et des journaux complets pour confirmer sa cause. Ce correctif n’affirme pas avoir réparé ffmpeg.
- Les vidéos insérées dans un carrousel mixte ne sont pas encore transcrites individuellement.
- Faire trois tests : un carrousel, un Reel déjà transcrit (« Réanalyser »), puis une nouvelle vidéo parlée ; vérifier le classement, les erreurs et le déplacement des catégories.
